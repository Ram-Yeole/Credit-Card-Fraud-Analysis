# 💳 Credit Card Transaction Fraud Analysis

## 📌 Project Overview

An end-to-end data analytics project analyzing **500,000 credit card transactions** to identify fraudulent activities, understand customer spending behavior, detect suspicious transaction patterns, and generate meaningful business insights using Python, MySQL, SQL, and Power BI.

## 🛠️ Technologies Used

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- MySQL
- SQL
- Power BI
- Jupyter Notebook

## 📊 Key Analysis

- Fraud vs Non-Fraud Transactions
- Customer Spending Analysis
- Merchant Category Analysis
- Hourly Transaction Trends
- Transaction Amount Analysis
- Geographical Fraud Analysis
- Payment Method Analysis
- Customer Risk Analysis
- Statistical Analysis and Business Insights

## 📈 Key Results

- **Total Transactions:** 500,000
- **Fraudulent Transactions:** 2,894
- **Non-Fraudulent Transactions:** 497,106
- **Fraud Rate:** 0.58%
- **Total Fraud Amount:** ₹15.82 Lakh
- **Average Transaction Amount:** 70.79
